Set up a Hartland stream

Follow this top to bottom the first time you set up a streaming PC (about 45 minutes). After that, game day is the short checklist in Game day. Tap the box on each step when it's done; this device remembers your progress.

The big picture

Four pieces work together. Knowing what each one does makes fixing problems much easier.

PieceWhere it runsWhat it does
ScorekeeperAny phone or computer (this site)You tap scores, pick players and characters, switch scenes and call instant replays. Everything on stream updates from here.
OBSThe streaming PCPuts the game, cameras and our graphics together and sends it to YouTube.
OverlaysInside OBS (Browser Sources)Our graphics: score bug, VS screens, stats, replays. They're web pages that follow whatever match is on their station.
LevelUP RelayThe streaming PC (a black window)Saves replay clips and plays them back, and feeds Rocket League's live stats to the score bug. Keep it open while streaming.
Stations: each streaming PC is a station (1, 2, 3 or 4). Station 1 is the main PC. A second PC streaming a different match at the same time is Station 2, and so on. Every link for a PC must use that PC's station number. The link maker in step 4 does this for you.

Step 1Get access Once

Sign in to the Scorekeeper

  1. Open the Scorekeeper and sign in with your @hartlandschools.us Google account.
  2. If it says you don't have access, ask a coach to add you as a scorekeeper for your team. Once they do, refresh the page.
Students can score, stream and run the OBS remote for their own team's matches. Final scores you submit go to a coach to approve before they show on the website.

Step 2OBS settings Once per PC

Do these on the streaming PC. Use OBS 30 or newer (Help › Check for Updates).

Video size: 1920 × 1080

  1. Open Settings › Video (Settings is at the bottom right of OBS).
  2. Set Base (Canvas) Resolution and Output (Scaled) Resolution both to 1920x1080.
  3. Set Common FPS Values to 60 (or 30 if the PC struggles). Click Apply.
All our graphics are drawn for exactly 1920 × 1080. Any other size and things land in the wrong spots.

Turn on the Replay Buffer

  1. Open Settings › Output.
  2. Find the Replay Buffer section (if Output Mode at the top says Advanced, it's on the Replay Buffer tab).
  3. Check Enable Replay Buffer and set Maximum Replay Time to 20 seconds.
  4. Under Recording, set Recording Format to MP4 (or Hybrid MP4). Click Apply.
The replay buffer quietly keeps the last 20 seconds of the stream. Instant replay saves it as a clip. Clips have to be MP4 to play back on the replay screen; MKV won't play.

Turn on the WebSocket server

  1. Open Tools › WebSocket Server Settings.
  2. Check Enable WebSocket server and Enable Authentication. Leave the port at 4455.
  3. Click Show Connect Info and keep that window open. You'll copy the Server Password in step 3.
This is how the LevelUP Relay asks OBS to save clips. The password keeps other computers from controlling OBS.

Optional: a Save Replay hotkey

Settings › Hotkeys, search Replay Buffer, click the box next to Save Replay, and press a key you won't hit by accident (like F9). Now whoever sits at the PC can save a replay without a phone.

Step 3The LevelUP Relay Once per PC

Download the relay

  1. On the streaming PC, make a folder on the Desktop called LevelUP Relay.
  2. Download all three files below and put them in that same folder:
levelup-rl-relay.ps1Start LevelUP Relay.batSet up highlight clips.bat
Updating: when a coach says the relay changed, download all three again and replace the old ones. Don't delete levelup-obs.dat; it holds the saved OBS password.

First run

  1. Open OBS first. Then double-click Start LevelUP Relay.bat.
  2. If Windows shows "Windows protected your PC", click More info › Run anyway. (It's our own script; Windows says this about anything downloaded.)
  3. When it asks for the OBS WebSocket password, copy the Server Password from step 2, right-click in the black window to paste, and press Enter. It's saved, so it only asks once.
  4. On a Rocket League PC, if it asks to turn on the Stats API, type Y and press Enter, then restart Rocket League.
  5. You should see green lines like Connected to OBS. Leave this window open the whole stream. Minimize it, don't close it.
On a PC that doesn't play Rocket League, the relay will say it couldn't find Rocket League. That's normal; replays still work.

Step 4Build the scenes Once per PC

A scene is one "screen" of the stream. You build them once; on game day you just switch between them.

How to add one of our overlays

  1. In the Scenes box (bottom left), click + and name the scene.
  2. In the Sources box, add your game first (Game Capture, Video Capture Device for a console capture card, or NDI Source).
  3. Click + › Browser, name it after the overlay (like Score bug), and click OK.
  4. Paste the overlay's link from the list below in URL. Set Width 1920 and Height 1080.
  5. Check Shutdown source when not visible and Refresh browser when scene becomes active. Click OK.
  6. Make sure the overlay is above the game in the Sources list (drag it to the top).
Exception: the LevelUP Remote source is the only one with "Shutdown source when not visible" unchecked. See step 5.

Step 5The OBS remote Once per PC

Lets the Scorekeeper switch scenes and call instant replays from any phone, anywhere in the lab.

Add the LevelUP Remote source

  1. In the Starting Soon scene, add a Browser source named LevelUP Remote with the LevelUP Remote link from step 4. Size doesn't matter; it's invisible.
  2. Uncheck Shutdown source when not visible. (It has to keep listening when that scene isn't on.)
  3. Set Page permissions to Advanced access to OBS. Click OK.
Page permissions is how OBS lets a web page switch scenes. "Advanced" allows switching scenes and saving replays, but not starting or stopping the stream.

Test it

  1. In the Scorekeeper, open your match and put it on this PC's station (On stream).
  2. Open the OBS remote section. It should say which scene is on air and show a button for every scene.
  3. Tap a different scene. OBS should switch within a second.
  4. Tap ⟲ Instant replay. OBS should save a clip and cut to Replay + Live, then come back after 15 seconds.

Game day Every stream

Once the PC is set up, this is all you do each time.

Before the match

  1. Open OBS, then double-click Start LevelUP Relay.bat.
  2. In the Scorekeeper, open the match. Under On stream, tap this PC's station.
  3. Fill in the opponent's lineup (gamertags) under On stream, and check our players under Players & stats.
  4. Check the OBS remote says it's connected.
  5. Click through each scene in OBS and make sure the graphics show the right teams.

Go live

  1. In OBS, click Start Streaming.
  2. Copy the YouTube live link into the match's Stream links so it shows on the website.
  3. Tap ● Live at the top of the match.

During the match

  • Score: tap who won each game (Smash: the Set desk; Fortnite: +1 rounds).
  • Replays: right after a great play, tap ⟲ Instant replay.
  • Scenes: use the OBS remote buttons (VS between games, Highlights, Be Right Back).

After the match

  1. Switch to Post Game, then tap Final (students: Submit final; a coach approves it).
  2. Stop the stream in OBS. Paste the replay link under Stream links › Replay (VOD) if it's different.
  3. Close the relay window. Clips are saved in Desktop › LevelUP Highlights.

Notes by game

Rocket League

The score bug reads the clock and goals straight from the game, so the relay must be running on the PC that runs Rocket League, with the Stats API on (the relay offers to turn it on). Under On stream, pick whether Hartland is blue or orange, or leave it on "work it out from player names". Goals and epic saves are clipped automatically for Highlights.

Super Smash Bros. Ultimate

Use the Set desk at the top of the match: tap our player and theirs; characters fill in from who they usually play. Tap a character to change it. Tap who won each game; two wins takes the set. Use the Smash VS screen between games.

Fortnite

Use the Corner score bug (it covers the island's own round counter) and a POV name plate for whoever's screen is showing. Rounds are tapped with +1; reaching 10 wins the game. For both players at once, use the Two POVs scene with two NDI sources.

Marvel Rivals and others

The standard Score bug and full-screen graphics work for every game. Tap who won each map; enter stats under Players & stats for the box score and post-game screens.

Fix it

Most problems are one of these.

An overlay is blank
  • Is the match on this PC's station? (Scorekeeper › match › On stream.)
  • Does the link's station number match this PC? Station 1 links have no station=; station 2 links end in station=2.
  • Right-click the source › Refresh.
An old graphic flashes when I switch scenes

That source needs Shutdown source when not visible checked (double-click the source to open its settings).

OBS remote says "Not connected"
  • Is OBS open, with the LevelUP Remote source in a scene?
  • Its Shutdown source when not visible must be unchecked.
  • Wrong station? Its link must match this PC's station.
  • Still nothing: right-click the source › Refresh, then wait 20 seconds.
Scene buttons show, but tapping does nothing

Set the LevelUP Remote source's Page permissions to Advanced access to OBS. The remote shows a yellow warning when this is the problem.

Replay screen says "No replay yet" or the replay never saves
  • Is the relay window open, and does it say Connected to OBS?
  • Is the Replay Buffer on? OBS shows a replay buffer button under Controls; the remote shows "Replays ready".
  • If the relay says the password is wrong, double-click Set up highlight clips.bat and paste the OBS password again.
"These clips are MKV files, which can't play here"

Settings › Output › Recording › Recording Format › MP4. New clips will play; old MKV ones won't.

Instant replay saves, but OBS doesn't switch scenes

The scene name in the Scorekeeper (On stream › Instant replay cuts to this OBS scene) must match the OBS scene name exactly, including capital letters and spaces.

Rocket League score bug says it can't connect
  • Start the relay on the PC running Rocket League.
  • If the relay says the Stats API is off, let it turn it on, then restart Rocket League.
  • Preview the score bug link with ?bg=1; the box at the top says exactly what's wrong.
Wrong names or characters on screen

Everything comes from the Scorekeeper: our players under Players & stats, theirs under On stream (or the Set desk for Smash). Fix it there and the stream updates within a second.
